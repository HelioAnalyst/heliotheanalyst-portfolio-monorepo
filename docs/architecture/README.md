# Architecture Documentation

This directory contains system architecture diagrams and documentation for all portfolio projects.

## Available Diagrams

| Project | Document | Description |
|---------|----------|-------------|
| Shopify Integration | [shopify-integration-system.md](./shopify-integration-system.md) | E-commerce sync architecture with rate limiting |
| Order Processing | [order-processing-automation.md](./order-processing-automation.md) | Async pipeline with idempotency |
| HelioScraper | [helioscraper-pipeline.md](./helioscraper-pipeline.md) | Web scraping pipeline with anti-detection |
| Data Analysis | [data-analysis-pipeline.md](./data-analysis-pipeline.md) | Analytics pipeline with forecasting |

## Diagram Types

Each architecture document includes:

- **High-Level Architecture**: System components and interactions
- **Data Flow Diagrams**: Sequence of operations
- **Component Architecture**: Internal module structure
- **Technology Stack**: List of technologies used
- **Key Design Decisions**: Rationale for architectural choices

## Viewing Diagrams

These diagrams use [Mermaid](https://mermaid.js.org/) syntax and can be viewed in:

- GitHub (native support)
- VS Code with Mermaid extension
- Any Markdown viewer with Mermaid plugin
- Online at [Mermaid Live Editor](https://mermaid.live/)
